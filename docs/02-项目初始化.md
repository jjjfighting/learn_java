# 学生管理系统 · 第二步：初始化 SpringBoot3 项目

> 本篇完成：创建 Maven 项目骨架、配置依赖与数据源、装配 MyBatis-Plus 分页插件、落盘建库脚本。

## 一、完成后的项目结构

```
learn_student_backend/
├── pom.xml                                   # Maven 依赖清单
├── sql/
│   └── init.sql                              # 建库建表 + 测试数据脚本
├── docs/                                     # 每一步的学习文档
│   ├── 01-数据库设计.md
│   └── 02-项目初始化.md
└── src/
    ├── main/
    │   ├── java/com/studentms/
    │   │   ├── StudentMsApplication.java     # 启动类
    │   │   └── config/
    │   │       └── MybatisPlusConfig.java    # 分页插件配置
    │   └── resources/
    │       └── application.yml               # 项目配置文件
    └── test/java/com/studentms/
        └── StudentMsApplicationTests.java    # 冒烟测试
```

约定：**所有 Java 类必须放在 `com.studentms` 包或其子包下**，否则启动类的组件扫描扫不到（原因见下文启动类说明）。

## 二、pom.xml 依赖说明

| 依赖 | 作用 | 为什么需要 |
|---|---|---|
| `spring-boot-starter-parent` 3.5.0 | 父工程 | 统一管理依赖版本，子依赖大多不用写 version，避免版本冲突 |
| `spring-boot-starter-web` | Web 开发 | 内置 Tomcat + SpringMVC，写 Controller 的基础 |
| `spring-boot-starter-validation` | 参数校验 | 提供 `@NotBlank`、`@Email`、`@Min` 等注解（本步先引入，后面模块用） |
| `mybatis-plus-spring-boot3-starter` 3.5.7 | ORM 框架 | 注意 artifactId 带 **boot3**——旧版 `mybatis-plus-boot-starter` 不兼容 SpringBoot3 |
| `mysql-connector-j` | MySQL 驱动 | `scope=runtime`：只在运行时连数据库，编译期不需要 |
| `lombok` | 简化代码 | 自动生成 getter/setter 等；`optional=true` 表示不传递给依赖方 |
| `spring-boot-starter-test` | 单元测试 | 内置 JUnit5 |

**环境要求**：JDK 17+（本机已装 Java 25，满足）；本机命令行暂无 Maven，后续直接用 IDEA 自带的 Maven 构建即可。

## 三、application.yml 关键配置讲解

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/student_ms?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
```

URL 参数逐个解释（初学者最常在这里报错）：

- `serverTimezone=Asia/Shanghai`：MySQL8 驱动要求显式指定时区，不写可能报时区错误；
- `useSSL=false`：本地开发不走 SSL，否则会有黄色警告；
- `allowPublicKeyRetrieval=true`：MySQL8 默认 `caching_sha2_password` 加密，不写这个可能报 `Public Key Retrieval is not allowed`。

```yaml
mybatis-plus:
  configuration:
    map-underscore-to-camel-case: true        # create_time -> createTime 自动映射
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl   # 控制台打印 SQL（调试神器）
  global-config:
    db-config:
      id-type: auto                           # 主键跟随数据库自增
      logic-delete-field: deleted             # 全局逻辑删除字段
      logic-delete-value: 1
      logic-not-delete-value: 0
```

- **SQL 日志**：开启后每次查询都会在控制台打印完整 SQL 和参数，学习阶段必开，上线关掉；
- **全局逻辑删除**：配置后所有实体类中带 `deleted` 字段的表自动生效——`removeById()` 实际执行 `UPDATE ... SET deleted=1`，所有查询自动追加 `WHERE deleted=0`，业务代码无感知。

> ⚠️ 记得把 `password` 改成你自己 MySQL 的密码。

## 四、启动类与分页插件讲解

### 启动类 `StudentMsApplication`

`@SpringBootApplication` 是组合注解，含三件套：

1. `@Configuration` —— 本类是配置类；
2. `@EnableAutoConfiguration` —— 自动配置（SpringBoot 核心魔法，按 classpath 里的依赖自动装配 Bean）；
3. `@ComponentScan` —— **默认只扫描本类所在包及子包**，所以启动类放在 `com.studentms` 根包，而不是某个子包里。

### 分页插件 `MybatisPlusConfig`

```java
@Bean
public MybatisPlusInterceptor mybatisPlusInterceptor() {
    MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
    interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
    return interceptor;
}
```

原理一句话：MyBatis-Plus 的分页不是"查完再截取"，而是这个拦截器在 SQL 执行前**自动改写 SQL 拼上 `LIMIT`**，所以必须注册它。不注册的典型症状：`selectPage()` 不报错，但返回的是全表数据——初学者第一大坑。

## 五、本地验证步骤

1. **建库**：在 MySQL 客户端（命令行 / Navicat / IDEA Database 面板均可）执行 `sql/init.sql`，执行完检查：
   ```sql
   USE student_ms;
   SHOW TABLES;              -- 应有 sys_user、clazz、course、student、score 五张表
   SELECT * FROM student;    -- 应有张三、李四两条数据
   ```
2. **导入项目**：IDEA 中 `File → Open` 选择项目根目录，识别为 Maven 项目，等待右下角依赖下载完成；
3. **改密码**：`application.yml` 中的 `password` 改成你本机 MySQL 密码；
4. **启动**：运行 `StudentMsApplication` 的 `main` 方法，控制台出现 `Started StudentMsApplication in x seconds` 即成功；
5. **（可选）跑测试**：运行 `StudentMsApplicationTests`，绿色通过说明容器装配无问题。

> 此时还没有任何接口，浏览器访问 `http://localhost:8080` 会返回 404 白页——这是正常的，说明 Tomcat 已启动，只是还没有 Controller。
